# Layer Cycle Manager (LCM)

> Нативная программа для AutoCAD, предназначенная для автоматического построения стрелок между точками, расположенными на разных слоях чертежа.  
> Программа является портом исходной Python-разработки `Layer Cycle Manager` на технологии AutoCAD: **AutoLISP / Visual LISP + ActiveX / COM**, с нативным **DCL-интерфейсом**, интеграцией в ленту AutoCAD через **CUIX**, сохранением настроек между запусками и автономным установщиком.

---

## 1. Назначение программы

Программа используется для визуализации связей между одноимёнными или вручную сопоставленными точками разных циклов расчёта.

Основная задача:

- выбрать слой с точками нулевого цикла;
- выбрать слой с точками последнего цикла;
- сопоставить точки между слоями автоматически или вручную;
- построить стрелки от точек нулевого слоя к точкам последнего слоя;
- подписать длину исходного отрезка в миллиметрах;
- разместить стрелки на целевом слое;
- назначить цвет:
  - по слою;
  - по индексу ACI;
  - по RGB.

Программа разрабатывается как автономный инструмент для AutoCAD, который можно устанавливать по аналогии с menuGEO:

- папка с файлами;
- одноразовая установка командой `LCMINSTALL`;
- загрузка интерфейса через `CUIX` и `_menuload`;
- кнопка запуска в ленте Ribbon;
- без установки Python и внешних библиотек.

## 3. Подтверждённые результаты Этапа 3

1. Чтение списка слоёв чертежа.
2. Чтение точек и текстов с выбранного слоя.
3. Сопоставление точки с ближайшим текстом.
4. Формирование имени точки:
   - если текст найден — имя берётся из текста;
   - если текст не найден — используется префикс:
     ```text
     Point_
     ```
     и handle точки.
5. Сортировка имён точек:
   - числовые имена сортируются по числовому значению;
   - строковые имена сортируются лексикографически.
6. Ручная отрисовка тестовой стрелки.
7. Автоматическая отрисовка стрелок по одинаковым именам.
8. Длина стрелки считается только по координатам `X` и `Y`.
9. Длина подписывается в миллиметрах:
   ```text
   длина в мм = длина в метрах × 1000
   ```
10. Округление длины выполняется по математическим правилам.
11. Масштаб влияет только на визуальное удлинение стрелки.
12. Текст длины не зависит от масштаба.
13. Наконечник стрелки строится как залитый треугольник `AcDbSolid`.
14. Все объекты стрелки размещаются на целевом слое.
15. Цвет стрелок берётся из целевого слоя через режим:
   ```lisp
   "BYLAYER"
   ```
16. Пакетная отрисовка обёрнута в один undo-блок, поэтому результат можно отменить одним `Ctrl + Z`.

## 4. Подтверждённые результаты Этапа 4

1. Команда `LCM` открывает нативный DCL-диалог AutoCAD.
2. Диалог содержит выбор нулевого и последнего слоёв.
3. Список слоёв заполняется автоматически при открытии диалога.
4. Кнопка «Обновить слои» обновляет список слоёв из текущего чертежа.
5. При выборе слоёв программа читает точки с соответствующих слоёв.
6. Информационная строка показывает количество найденных точек на нулевом и последнем слоях.
7. Реализован выбор режима цвета:
   - «По слою»;
   - `ACI`;
   - `RGB`.
8. Режим «По слою» использует:
   ```lisp
   "BYLAYER"
   ```
   и стрелки наследуют цвет целевого слоя.
9. Режим `ACI` позволяет задать цвет по индексу от 1 до 255.
10. Режим `RGB` позволяет задать TrueColor-цвет вручную через значения R, G, B.
11. Поля, не относящиеся к выбранному режиму цвета, блокируются.
12. Реализована настройка высоты текста.
13. Реализована настройка масштаба стрелок.
14. Реализован список сопоставлений точек.
15. Реализовано автоматическое сопоставление точек по одинаковым именам.
16. Если точка с таким же именем не найдена, создаётся запись с placeholder:
   ```text
   <not found>
   ```
17. Реализовано ручное добавление сопоставлений через выпадающие списки.
18. Реализовано обновление выбранного сопоставления.
19. Реализовано удаление выбранного сопоставления.
20. Реализована очистка всех сопоставлений.
21. Кнопка «Выполнить» проверяет ввод и запускает отрисовку стрелок.
22. Некорректные сопоставления пропускаются.
23. После нажатия «Выполнить» диалог закрывается, а стрелки строятся в AutoCAD.
24. Кнопка «Закрыть» закрывает диалог без выполнения отрисовки.

## 5. Подтверждённые результаты Этапа 5

1. Создан частичный файл пользовательского интерфейса:
   ```text
   lcm.cuix
   ```
2. Файл сохранён в папке проекта и не затрагивает основной `acad.cuix`.
3. В CUIX создана команда:
   ```text
   Layer Cycle Manager
   ```
4. Команде назначен макрос, который при необходимости сам подгружает LISP-код:
   ```text
   ^C^C^P(if (not lcm:loaded)(progn (if (findfile "lcm_main.lsp")(load "lcm_main.lsp")(alert "LCM: файл lcm_main.lsp не найден. Добавьте папку LayerCycleManager в Support File Search Path."))));LCM;
   ```
5. В Ribbon создана вкладка:
   ```text
   Layer Cycle Manager
   ```
6. На вкладке создана панель:
   ```text
   Стрелки
   ```
7. На панель добавлена кнопка запуска программы.
8. Кнопке назначен стиль:
   ```text
   Большой с текстом (вертикально)
   ```
   такой же стиль используется в menuGEO для больших кнопок.
9. Кнопке назначена собственная иконка-стрелка:
   ```text
   icons/arrow.png
   ```
   исходник 230×230 пикселей.
10. Иконка встроена внутрь `lcm.cuix`, поэтому на других компьютерах кнопка отображается со своей иконкой без папки `icons`.
11. Файл `lcm.cuix` загружается стандартной командой:
   ```text
   _MENULOAD
   ```
12. При нажатии кнопки на ленте:
   - при необходимости подгружается `lcm_main.lsp`;
   - запускается команда `LCM`;
   - открывается DCL-диалог программы.
13. Если папка проекта не добавлена в Support File Search Path, выводится понятное предупреждение.
14. Обновление CUIX выполняется через выгрузку и повторную загрузку:
   ```text
   _MENUUNLOAD
   _MENULOAD
   ```
15. Дополнительно в CUIX создано пульдаун-меню:
   ```text
   Меню → Layer Cycle Manager
   ```
   которое отображается в классической строке меню при включённой переменной `MENUBAR`.

## 6. Подтверждённые результаты Этапа 6

1. Реализован модуль настроек:
   ```text
   lcm_config.lsp
   ```
2. Настройки сохраняются в файл:
   ```text
   settings/lcm_settings.cfg
   ```
3. Папка `settings` и файл настроек создаются автоматически при первом сохранении.
4. Настройки сохраняются при нажатии кнопки:
   ```text
   Выполнить
   ```
   после успешной проверки всех полей.
5. При нажатии кнопки:
   ```text
   Закрыть
   ```
   настройки не сохраняются — сохраняются только реально использованные параметры.
6. При повторном открытии диалога восстанавливаются:
   - последний нулевой слой;
   - последний последний слой;
   - масштаб;
   - высота текста;
   - режим цвета;
   - значение ACI;
   - значения RGB.
7. Блокировка цветовых полей соответствует восстановленному режиму цвета.
8. Сохранённый радиус поиска текста применяется к переменной:
   ```lisp
   lcm:text-search-radius
   ```
   при загрузке модулей.
9. Если файл настроек отсутствует, программа открывается со значениями по умолчанию.
10. Если файл настроек повреждён, программа выводит предупреждение и работает со значениями по умолчанию.
11. Если сохранённый слой был удалён или переименован в чертеже, выбирается первый слой из списка — программа не падает.
12. Файл настроек исключён из Git через `.gitignore`, поэтому личные настройки не попадают в репозиторий.
13. Исправлена особенность AutoLISP: функция `read` принимает только строку, поэтому файл настроек читается через `read-line` с последующим разбором строки.

### Сохраняемые параметры

| Ключ | Назначение |
|---|---|
| `LAYER_ZERO` | последний выбранный нулевой слой |
| `LAYER_LAST` | последний выбранный последний слой |
| `COLOR_MODE` | режим цвета: 0 — по слою, 1 — ACI, 2 — RGB |
| `ACI` | последний использованный индекс ACI |
| `RGB` | последний использованный RGB-цвет |
| `TEXT_HEIGHT` | последняя высота текста |
| `SCALE` | последний масштаб |
| `TEXT_SEARCH_RADIUS` | радиус поиска текста около точки |



   ```text
   Trusted Locations
   ```
   через системную переменную `TRUSTEDPATHS`.

   ```text
   LCM_PATH
   ```

   ```text
   lcm_main.lsp
   ```
7. Установщик загружает:
   ```text
   lcm.cuix
   ```
   через `_menuload` в принудительном командном режиме (`FILEDIA = 0`), чтобы путь передавался напрямую без диалогового окна.
8. Реализован флаг:
   ```text
   LCM_CUIX_LOADED
   ```
   который пропускает повторный `menuload` на уже настроенных машинах и исключает зависания на повторных запросах.
9. Создана инструкция:
   ```text
   INSTALL.txt
   ```
   с порядком установки, переноса и удаления программы.
10. Версия программы поднята до:
   ```text
   0.3.0
   ```
11. Проверена чистая установка: после полного удаления программы (выгрузка CUIX, очистка путей и переменных, перезапуск AutoCAD) установка с нуля проходит успешно и без ручной настройки Support Path.
12. После перезапуска AutoCAD программа работает без повторной установки: пути и CUIX сохраняются в профиле.
13. Подготовлена схема передачи программы коллегам:
   - клонирование с GitHub;
   - или ZIP-архив без `.git` и без `settings/lcm_settings.cfg` вместе с `INSTALL.txt`.

### 10.5. `lcm_data.lsp`

Модуль работы с данными чертежа.

Отвечает за:

- получение списка слоёв;
- поиск точек на указанном слое;
- поиск текстов и мультитекстов на указанном слое;
- сопоставление каждой точки с ближайшим текстом;
- формирование имени точки;
- сортировку имён точек;
- автоматическое сопоставление точек двух слоёв.

#### Основные сущности файла

| Имя | Тип | Назначение |
|---|---|---|
| `lcm:text-search-radius` | переменная | радиус поиска текста около точки |
| `lcm:unnamed-point-prefix` | переменная | префикс для точек без текста |
| `lcm:get-layers` | функция | получить список слоёв чертежа |
| `lcm:get-points-with-names` | функция | получить точки слоя с именами |
| `lcm:get-object-coords` | функция | получить координаты объекта |
| `lcm:get-object-handle` | функция | получить handle объекта |
| `lcm:is-numeric` | функция | проверка, является ли имя числом |
| `lcm:name<` | функция | сравнение имён для сортировки |
| `lcm:sort-points` | функция | сортировка списка точек |
| `lcm:add-or-replace-point` | функция | добавление или замена точки в списке |
| `lcm:get-point-names` | функция | получить только имена точек |
| `lcm:auto-mappings` | функция | автоматическое сопоставление точек |
| `C:LCMLAYERS` | команда AutoCAD | вывести список слоёв |

```text
^C^C^P(if (not lcm:loaded)(progn (if (findfile "lcm_main.lsp")(load "lcm_main.lsp")(alert "LCM: файл lcm_main.lsp не найден. Добавьте папку LayerCycleManager в Support File Search Path."))));LCM;
```

### 10.13. `loader/lcm_loader.lsp`

Установщик программы.

Файл реализован и содержит команду:

```text
LCMINSTALL
```

Алгоритм работы:

1. Запрашивает у пользователя файл:
   ```text
   lcm_main.lsp
   ```
   через `getfiled` — так установщик узнаёт путь к папке программы.
2. Нормализует слеши пути.
3. Добавляет папку в Support File Search Path через переменную окружения:
   ```lisp
   (setenv "ACAD" ...)
   ```
   если папки там ещё нет.
4. Добавляет папку в Trusted Locations через:
   ```lisp
   (setvar "TRUSTEDPATHS" ...)
   ```
   если папки там ещё нет.
5. Сохраняет путь в переменную окружения:
   ```text
   LCM_PATH
   ```
6. Загружает:
   ```text
   lcm_main.lsp
   ```
7. Если флаг:
   ```text
   LCM_CUIX_LOADED
   ```
   не установлен, временно переключает:
   ```lisp
   FILEDIA = 0
   ```
   и вызывает:
   ```lisp
   (command "_menuload" cuix-path)
   ```
   чтобы путь передавался напрямую в командной строке без диалогового окна.
8. Устанавливает флаг:
   ```text
   LCM_CUIX_LOADED = 1
   ```
   чтобы при повторных запусках установщика не выполнять `menuload` повторно.
9. Выводит итоговое сообщение об успешной установке.

### 12.2. Функции `lcm_data.lsp`

#### `lcm:get-layers`

```lisp
(lcm:get-layers)
```

Возвращает отсортированный список слоёв текущего чертежа.

Используется для заполнения выпадающих списков в интерфейсе.

---

#### `lcm:get-points-with-names`

```lisp
(lcm:get-points-with-names "Уч.4 Цикл 0")
```

Основная функция получения данных со слоя.

Алгоритм:

1. Сканирует объекты Model Space.
2. Отбирает объекты указанного слоя.
3. Собирает:
   - точки `AcDbPoint`;
   - тексты `AcDbText`;
   - мультитексты `AcDbMText`.
4. Для каждой точки ищет ближайший текст.
5. Если текст найден, имя точки равно тексту.
6. Если текст не найден, имя формируется как:

```text
Point_<Handle>
```

7. Возвращает отсортированный список вида:

```lisp
(
  ("1" . (100.0 200.0))
  ("2" . (150.0 220.0))
  ("Point_1A2B" . (180.0 260.0))
)
```

---

#### `lcm:get-object-coords`

```lisp
(lcm:get-object-coords obj)
```

Получает координаты объекта.

Сначала пытается использовать:

```lisp
Coordinates
```

Если не получается, пытается использовать:

```lisp
InsertionPoint
```

Возвращает список:

```lisp
(x y)
```

---

#### `lcm:get-object-handle`

```lisp
(lcm:get-object-handle obj)
```

Возвращает handle объекта.

Используется для формирования имени точки, если рядом нет текста.

---

#### `lcm:is-numeric`

```lisp
(lcm:is-numeric "12")
```

Проверяет, является ли строка числом.

Примеры:

| Значение | Результат |
|---|---|
| `"12"` | `T` |
| `"12.5"` | `T` |
| `"-7"` | `T` |
| `"12a"` | `nil` |
| `"abc"` | `nil` |

---

#### `lcm:name<`

```lisp
(lcm:name< "2" "10")
```

Функция сравнения имён для сортировки.

Правила:

- числовые имена сортируются по числовому значению;
- нечисловые имена сортируются лексикографически;
- числовые имена идут перед нечисловыми.

---

#### `lcm:sort-points`

```lisp
(lcm:sort-points points)
```

Сортирует список точек по имени.

---

#### `lcm:add-or-replace-point`

```lisp
(lcm:add-or-replace-point pairs name coord)
```

Добавляет точку в список.

Если точка с таким именем уже существует, она заменяется новой.

---

#### `lcm:get-point-names`

```lisp
(lcm:get-point-names points)
```

Возвращает только имена точек без координат.

---

#### `lcm:auto-mappings`

```lisp
(lcm:auto-mappings points-zero points-last)
```

Создаёт автоматические сопоставления.

Принцип:

- для каждой точки нулевого слоя ищется точка с таким же именем в последнем слое;
- если совпадение найдено, создаётся пара:

```lisp
((from . "1") (to . "1"))
```

- если совпадение не найдено, пара не создаётся.

Назначает объекту:

| Режим | Описание |
|---|---|

#### `lcm:draw-arrow`

```lisp
(lcm:draw-arrow
  start-point
  end-point
  layer-name
  color-mode
  color-data
  text-height
  scale
)
```

Рисует одну стрелку.

Параметры:

| Параметр | Назначение |
|---|---|
| `start-point` | начальная точка |
| `end-point` | конечная точка |
| `layer-name` | слой для объектов стрелки |
| `color-mode` | режим цвета |
| `color-data` | данные цвета |
| `text-height` | высота текста |
| `scale` | масштаб удлинения стрелки |

Геометрия:

- линия рисуется от `start` до:
  ```text
  start + (end - start) * scale
  ```
- длина текста считается по исходным точкам без учёта `scale`;
- длина переводится в миллиметры:
  ```text
  length * 1000
  ```
- округление выполняется по математическим правилам;
- наконечник — залитый треугольник `AcDbSolid`;
- угол при вершине наконечника — 20°;
- длина крыла наконечника:
  ```text
  0.2 * length * scale
  ```

```lisp
  scale

  text-height
```

3. Проверяет наличие точек.
4. Запускает отрисовку для каждого сопоставления.
5. Обёртывает процесс в один undo-блок:
   ```lisp
   vla-StartUndoMark
   vla-EndUndoMark
   ```
6. Выводит количество созданных стрелок.
7. Выводит количество ошибок.

### 12.6. Функции `loader/lcm_loader.lsp`

#### `C:LCMINSTALL`

```text
LCMINSTALL
```

Одноразовый установщик программы.

Действие:

1. Через `getfiled` запрашивает выбор файла:
   ```text
   lcm_main.lsp
   ```
   и определяет папку программы.
2. Нормализует слеши пути через `vl-string-translate`.
3. Добавляет папку в Support File Search Path:

4. Добавляет папку в Trusted Locations:

6. Загружает:
   ```lisp
   (load (strcat path "/lcm_main.lsp"))
   ```
7. Если `LCM_CUIX_LOADED` не равен `"1"`:
   - переключает `FILEDIA` в 0;
   - вызывает `(command "_menuload" cuix-path)`;
   - возвращает `FILEDIA`;
   - устанавливает `LCM_CUIX_LOADED = 1`.
8. Выводит сообщение об успешной установке.

## 15. Важные допущения и правила

### 15.1. Единицы чертежа

На текущем этапе предполагается, что чертёж выполнен в метрах.

Длина в тексте стрелки рассчитывается так:

```text
длина в мм = длина в метрах * 1000
```

Округление выполняется до целого числа.

---

### 15.2. Пространство объектов

На текущем этапе программа сканирует:

```text
ModelSpace
```

Объекты в Layout, блоках или XREF пока не обрабатываются.

---

### 15.3. Цвет объектов

Текущая целевая логика:

```text
Цвет стрелки = цвет слоя, на котором создана стрелка
```

Для этого используется режим:

```lisp
"BYLAYER"
```

---

### 15.4. Длина стрелки и масштаб

Длина текста всегда считается по исходным точкам.

Масштаб влияет только на визуальное удлинение линии:

```text
конец линии = start + (end - start) * scale
```

---

### 15.5. Размеры иконок Ribbon

Лента Ribbon имеет фиксированные метрики кнопок:

- большая кнопка — иконка 32×32 логических пикселя;
- маленькая кнопка — иконка 16×16.

Размер отображения кнопки задаётся стилем кнопки в CUI, а не размером файла иконки.

Большие исходники (230×230 у LCM, 215×215 у menuGEO) нужны только как источники высокого разрешения для чёткого отображения при масштабировании Windows и на HiDPI-мониторах.

---

### 15.6. Правила сохранения настроек

- Настройки сохраняются только при нажатии «Выполнить».
- Настройки не сохраняются при нажатии «Закрыть».
- Файл настроек хранится локально и не попадает в Git.
- Путь к файлу настроек зависит от расположения `lcm_main.lsp`, поэтому папка проекта должна быть добавлена в Support File Search Path (делается установщиком автоматически).

---

### 15.7. Правила установки и удаления

- Установка выполняется один раз на компьютере командой:
  ```text
  LCMINSTALL
  ```
- После установки пути и CUIX сохраняются в профиле AutoCAD, поэтому при следующих запусках установка не требуется.
- При переносе папки программы в другое место нужно повторно выполнить `LCMINSTALL`.
- Удаление программы выполняется через:
  ```text
  _MENUUNLOAD
  ```
  (не `CUIUNLOAD` — такой команды не существует), очистку путей в OPTIONS и удаление переменных окружения.

---

## 16. Как запустить программу


- папка добавится в Support File Search Path;
- папка добавится в Trusted Locations;
- загрузится программа;
- загрузится `lcm.cuix`;
- в Ribbon появится вкладка:
  ```text
  Layer Cycle Manager
  ```

### 16.3. Запуск из командной строки

## 18. Известные ограничения текущей версии

1. Интерфейс реализован на DCL, но имеет ограничения DCL:
   - сопоставления отображаются обычным списком;
   - редактирование выполняется через отдельные выпадающие списки;
   - нет полноценной таблицы с combobox в каждой строке.
2. Выбор цвета через системный диалог пока доступен только для ACI и только если функция `acad_colordlg` поддерживается в конкретной версии AutoCAD.
3. RGB вводится вручную через поля R, G, B.
4. Объекты читаются только из Model Space.
5. Радиус поиска текста меняется только через файл настроек или переменную:
   ```lisp
   lcm:text-search-radius
   ```
   поля для него в диалоге пока нет.
6. Форматирование MText обрабатывается упрощённо.
7. Единицы чертежа пока жёстко считаются метрами.
8. Пульдаун-меню программы отображается только при включённой строке меню (`MENUBAR = 1`) и после добавления меню в текущее рабочее пространство.
9. Настройки сохраняются только при нажатии «Выполнить».

## 23. Примечание по Ribbon и иконкам

1. Размер кнопки на ленте задаётся стилем кнопки в CUI, а не размером файла иконки.
2. Для больших кнопок используется стиль:
   ```text
   Большой с текстом (вертикально)
   ```
3. Физический предел иконки на ленте — слот большой кнопки (32×32 логических пикселя).
4. Большие исходники иконок нужны только для чёткости при масштабировании.
5. Иконки, назначенные через CUI, встраиваются в `lcm.cuix` и работают на других компьютерах без папки `icons`.

## 24. Примечание по пульдаун-меню

1. Пульдаун-меню программы:
   ```text
   Меню → Layer Cycle Manager
   ```
   отображаются только в классической строке меню AutoCAD.
2. Строка меню включается командой:
   ```text
   MENUBAR
   ```
   со значением:
   ```text
   1
   ```
3. Если строка меню включена, но пункта нет, меню нужно добавить в текущее рабочее пространство:
   - `CUI`;
   - выбрать текущее рабочее пространство;
   - «Настройка рабочего пространства» (Customize Workspace);
   - поставить флажок напротив:
     ```text
     LCM → Меню → Layer Cycle Manager
     ```
   - «Готово» (Done);
   - Применить / OK.
4. Меню должно быть верхнего уровня: находиться прямо под узлом «Меню» файла `lcm.cuix`.
