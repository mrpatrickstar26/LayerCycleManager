# Layer Cycle Manager (LCM)

> Нативная программа для AutoCAD, предназначенная для автоматического построения стрелок между точками, расположенными на разных слоях чертежа.  
> Программа является портом исходной Python-разработки `Layer Cycle Manager` на технологии AutoCAD: **AutoLISP / Visual LISP + ActiveX / COM**, с дальнейшим переходом на **DCL** и **CUIX**.

---

## 1. Назначение программы

Программа используется для визуализации связей между одноимёнными или вручную сопоставленными точками разных циклов расчёта.

Основная задача:

- выбрать слой с точками нулевого цикла;
- выбрать слой с точками последнего цикла;
- сопоставить точки между слоями автоматически или вручную;
- построить стрелки от точек нулевого слоя к точкам последнего слоя;
- подписать длину исходного отрезка в миллиметрах;
- разместить стрелки на целевом слое;
- назначить цвет:
  - по слою;
  - по индексу ACI;
  - в перспективе — по RGB.

Программа разрабатывается как автономный инструмент для AutoCAD, который в дальнейшем можно будет устанавливать по аналогии с menuGEO:

- папка с файлами;
- загрузка интерфейса через `CUIX`;
- без установки Python и внешних библиотек.

## 3. Подтверждённые результаты Этапа 3

По состоянию на текущую версию подтверждено, что работает:

1. Чтение списка слоёв чертежа.
2. Чтение точек и текстов с выбранного слоя.
3. Сопоставление точки с ближайшим текстом.
4. Формирование имени точки:
   - если текст найден — имя берётся из текста;
   - если текст не найден — используется префикс:
     ```text
     Point_
     ```
     и handle точки.
5. Сортировка имён точек:
   - числовые имена сортируются по числовому значению;
   - строковые имена сортируются лексикографически.
6. Ручная отрисовка тестовой стрелки.
7. Автоматическая отрисовка стрелок по одинаковым именам.
8. Длина стрелки считается только по координатам `X` и `Y`.
9. Длина подписывается в миллиметрах:
   ```text
   длина в мм = длина в метрах × 1000
   ```
10. Округление длины выполняется по математическим правилам.
11. Масштаб влияет только на визуальное удлинение стрелки.
12. Текст длины не зависит от масштаба.
13. Наконечник стрелки строится как залитый треугольник `AcDbSolid`.
14. Все объекты стрелки размещаются на целевом слое.
15. Цвет стрелок берётся из целевого слоя через режим:
   ```lisp
   "BYLAYER"
   ```
16. Пакетная отрисовка обёрнута в один undo-блок, поэтому результат можно отменить одним `Ctrl + Z`.

## 8.1. Функции `lcm_main.lsp`

### `lcm:load-module`

```lisp
(lcm:load-module "lcm_data.lsp")
```

Безопасно загружает модуль.

Действие:

1. Ищет файл через `findfile`.
2. Если файл найден — загружает его.
3. Если файла нет — продолжает работу.
4. При ошибке загрузки выводит сообщение.

---

### `lcm:load-modules`

```lisp
(lcm:load-modules)
```

Загружает модули проекта в правильном порядке:

```text
lcm_config.lsp
lcm_data.lsp
lcm_core.lsp
lcm_ui.lsp
```

Перед загрузкой сбрасывает флаг:

```lisp
lcm:ui-loaded
```

---

### `lcm:start`

```lisp
(lcm:start)
```

Главная функция запуска.

На текущем этапе:

- выводит версию программы;
- проверяет флаг готовности интерфейса;
- если интерфейс готов, должна вызвать:
  ```lisp
  lcm:show-main-dialog
  ```
- если интерфейс не готов, выводит сообщение:
  ```text
  LCM: UI is not implemented yet. Command LCM works.
  ```

## 8.2. Функции `lcm_data.lsp`

### `lcm:get-layers`

```lisp
(lcm:get-layers)
```

Возвращает отсортированный список слоёв текущего чертежа.

Используется для заполнения будущих выпадающих списков в интерфейсе.

---

### `lcm:get-points-with-names`

```lisp
(lcm:get-points-with-names "Уч.4 Цикл 0")
```

Основная функция получения данных со слоя.

Алгоритм:

1. Сканирует объекты Model Space.
2. Отбирает объекты указанного слоя.
3. Собирает:
   - точки `AcDbPoint`;
   - тексты `AcDbText`;
   - мультитексты `AcDbMText`.
4. Для каждой точки ищет ближайший текст.
5. Если текст найден, имя точки равно тексту.
6. Если текст не найден, имя формируется как:

```text
Point_<Handle>
```

7. Возвращает отсортированный список вида:

```lisp
(
  ("1" . (100.0 200.0))
  ("2" . (150.0 220.0))
  ("Point_1A2B" . (180.0 260.0))
)
```

---

### `lcm:get-object-coords`

```lisp
(lcm:get-object-coords obj)
```

Получает координаты объекта.

Сначала пытается использовать:

```lisp
Coordinates
```

Если не получается, пытается использовать:

```lisp
InsertionPoint
```

Возвращает список:

```lisp
(x y)
```

---

### `lcm:get-object-handle`

```lisp
(lcm:get-object-handle obj)
```

Возвращает handle объекта.

Используется для формирования имени точки, если рядом нет текста.

---

### `lcm:is-numeric`

```lisp
(lcm:is-numeric "12")
```

Проверяет, является ли строка числом.

Примеры:

| Значение | Результат |
|---|---|
| `"12"` | `T` |
| `"12.5"` | `T` |
| `"-7"` | `T` |
| `"12a"` | `nil` |
| `"abc"` | `nil` |

---

### `lcm:name<`

```lisp
(lcm:name< "2" "10")
```

Функция сравнения имён для сортировки.

Правила:

- числовые имена сортируются по числовому значению;
- нечисловые имена сортируются лексикографически;
- числовые имена идут перед нечисловыми.

---

### `lcm:sort-points`

```lisp
(lcm:sort-points points)
```

Сортирует список точек по имени.

---

### `lcm:add-or-replace-point`

```lisp
(lcm:add-or-replace-point pairs name coord)
```

Добавляет точку в список.

Если точка с таким именем уже существует, она заменяется новой.

---

### `lcm:get-point-names`

```lisp
(lcm:get-point-names points)
```

Возвращает только имена точек без координат.

---

### `lcm:auto-mappings`

```lisp
(lcm:auto-mappings points-zero points-last)
```

Создаёт автоматические сопоставления.

Принцип:

- для каждой точки нулевого слоя ищется точка с таким же именем в последнем слое;
- если совпадение найдено, создаётся пара:

```lisp
((from . "1") (to . "1"))
```

- если совпадение не найдено, пара не создаётся.

---

### `C:LCMLAYERS`

```text
LCMLAYERS
```

Тестовая команда.

Выводит список слоёв чертежа в командную строку AutoCAD.

---

### `C:LCMTESTDATA`

```text
LCMTESTDATA
```

Тестовая команда.

Запрашивает имя слоя и выводит найденные точки:

```text
1  X=100.000  Y=200.000
2  X=150.000  Y=220.000
```

```lisp
(lcm:is-string "text")
```

Проверяет, является ли значение строкой.

Заменяет отсутствующую в AutoLISP функцию `stringp`.

### `lcm:distance-2d`

```lisp
(lcm:distance-2d p1 p2)
```

Вычисляет расстояние между двумя точками только по координатам X и Y.

Координата Z игнорируется.

Это соответствует логике исходного Python-скрипта:

```python
math.hypot(dx, dy)
```

```lisp
(lcm:ensure-layer "MyLayer")
```

Проверяет наличие слоя.

Если слой отсутствует, пытается создать его.

### `lcm:set-object-properties`

```lisp
(lcm:set-object-properties obj layer-name color-mode color-data)
```

Назначает объекту:

- слой;
- цвет.

Поддерживаемые режимы цвета:

| Режим | Описание |
|---|---|
| `"BYLAYER"` | цвет берётся из слоя объекта |
| `"ACI"` | цвет по индексу AutoCAD Color Index |
| `"RGB"` | TrueColor RGB |

Для режима:

```lisp
"BYLAYER"
```

устанавливается цвет:

```lisp
256
```

### `lcm:draw-arrow`

```lisp
(lcm:draw-arrow
  start-point
  end-point
  layer-name
  color-mode
  color-data
  text-height
  scale
)
```

Рисует одну стрелку.

Параметры:

| Параметр | Назначение |
|---|---|
| `start-point` | начальная точка |
| `end-point` | конечная точка |
| `layer-name` | слой для объектов стрелки |
| `color-mode` | режим цвета |
| `color-data` | данные цвета |
| `text-height` | высота текста |
| `scale` | масштаб удлинения стрелки |

Геометрия:

- линия рисуется от `start` до:
  ```text
  start + (end - start) * scale
  ```
- длина текста считается по исходным точкам без учёта `scale`;
- длина переводится в миллиметры:
  ```text
  length * 1000
  ```
- округление выполняется по математическим правилам;
- наконечник — залитый треугольник `AcDbSolid`;
- угол при вершине наконечника — 20°;
- длина крыла наконечника:
  ```text
  0.2 * length * scale
  ```

### `lcm:run`

```lisp
(lcm:run
  layer-zero
  layer-last
  mappings
  scale
  color-mode
  color-data
  text-height
)
```

Главная функция пакетной отрисовки.

Действие:

1. Получает точки нулевого слоя.
2. Получает точки последнего слоя.
3. Проверяет наличие точек.
4. Запускает отрисовку для каждого сопоставления.
5. Обёртывает процесс в один undo-блок:
   ```lisp
   vla-StartUndoMark
   vla-EndUndoMark
   ```
6. Выводит количество созданных стрелок.
7. Выводит количество ошибок.

---

### `C:LCMTESTDRAW`

```text
LCMTESTDRAW
```

Тестовая команда ручной отрисовки.

Порядок работы:

1. Указать начальную точку.
2. Указать конечную точку.
3. Ввести слой для стрелки.
4. Ввести масштаб.

Текущее поведение:

- стрелка создаётся на указанном слое;
- цвет объектов наследуется от указанного слоя;
- используется режим:
  ```lisp
  "BYLAYER"
  ```

---

### `C:LCMTESTRUN`

```text
LCMTESTRUN
```

Тестовая команда автоматической отрисовки.

Порядок работы:

1. Ввести имя нулевого слоя.
2. Ввести имя последнего слоя.
3. Ввести масштаб.

Действие:

- читает точки с обоих слоёв;
- создаёт автоматические сопоставления по одинаковым именам;
- рисует стрелки на последнем слое;
- цвет стрелок берётся из последнего слоя.

## 11. Важные допущения и правила

### 11.1. Единицы чертежа

На текущем этапе предполагается, что чертёж выполнен в метрах.

Длина в тексте стрелки рассчитывается так:

```text
длина в мм = длина в метрах * 1000
```

Округление выполняется до целого числа.

---

### 11.2. Пространство объектов

На текущем этапе программа сканирует:

```text
ModelSpace
```

Объекты в Layout, блоках или XREF пока не обрабатываются.

---

### 11.3. Цвет объектов

Текущая целевая логика:

```text
Цвет стрелки = цвет слоя, на котором создана стрелка
```

Для этого используется режим:

```lisp
"BYLAYER"
```

---

### 11.4. Длина стрелки и масштаб

Длина текста всегда считается по исходным точкам.

Масштаб влияет только на визуальное удлинение линии:

```text
конец линии = start + (end - start) * scale
```

## 14. Известные ограничения текущей версии

1. Нет графического интерфейса.
2. Нет DCL-диалога.
3. Нет CUIX-интеграции.
4. Нет сохранения настроек.
5. Нет выбора цвета через диалог.
6. RGB-режим поддерживается ядром, но пока не используется в тестовых командах.
7. Объекты читаются только из Model Space.
8. Радиус поиска текста пока задаётся только переменной:
   ```lisp
   lcm:text-search-radius
   ```
9. Форматирование MText обрабатывается упрощённо.
10. Единицы чертежа пока жёстко считаются метрами.
