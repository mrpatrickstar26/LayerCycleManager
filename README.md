# Layer Cycle Manager (LCM)

> Нативная программа для AutoCAD, предназначенная для автоматического построения стрелок между точками, расположенными на разных слоях чертежа.  
> Реализована полностью на технологиях AutoCAD: **AutoLISP / Visual LISP + ActiveX / COM**, с нативным **DCL-интерфейсом**, интеграцией в ленту через **CUIX**, сохранением настроек и автономной установкой.  
> Версия: **0.3.0**

---

## 1. Назначение программы

Программа используется для визуализации связей между одноимёнными или вручную сопоставленными точками разных циклов расчёта (например, для отрисовки стрелок-отклонений шпунта).

Основная задача:

- выбрать слой с точками нулевого цикла;
- выбрать слой с точками последнего цикла;
- сопоставить точки между слоями автоматически или вручную (включая ручной ввод имён с клавиатуры);
- построить стрелки от точек нулевого слоя к точкам последнего слоя;
- подписать длину исходного отрезка в миллиметрах;
- разместить стрелки на целевом слое;
- назначить цвет: «по слою» (галочка) или по индексу ACI (включая выбор через родную палитру AutoCAD);
- при необходимости удалить ранее построенные стрелки с выбранного слоя.

## 3. Установка и удаление

### 3.1. Требования

- AutoCAD 2018 и новее (полная версия, не LT).

---

### 3.2. Способ 1 — установщик (рекомендуемый)

1. Скопировать папку проекта:
   ```text
   LayerCycleManager
   ```
   в удобное место.
2. В AutoCAD выполнить:
   ```text
   APPLOAD
   ```
3. Загрузить файл:
   ```text
   LayerCycleManager/loader/lcm_loader.lsp
   ```
4. Выполнить команду:
   ```text
   LCMINSTALL
   ```
5. В появившемся окне выбора файла указать:
   ```text
   LayerCycleManager/lcm_main.lsp
   ```

Установщик автоматически:

- добавит папку в Support File Search Path;
- добавит папку в Trusted Locations;
- загрузит программу;
- загрузит `lcm.cuix`.

После этого в Ribbon появится вкладка:

```text
Layer Cycle Manager
```

---

### 3.3. Способ 2 — вручную через параметры AutoCAD и `_MENULOAD`

1. Открыть параметры AutoCAD:
   ```text
   OPTIONS
   ```
2. На вкладке:
   ```text
   Files
   ```
   добавить папку программы в:
   - Support File Search Path;
   - Trusted Locations.
3. Выполнить команду:
   ```text
   _MENULOAD
   ```
4. В открывшемся окне выбрать файл:
   ```text
   LayerCycleManager/lcm.cuix
   ```
   и нажать:
   ```text
   Load
   ```
5. В Ribbon появится вкладка:
   ```text
   Layer Cycle Manager
   ```

---

### 3.4. Запуск программы

- кнопка на панели:
  ```text
  Стрелки
  ```
  вкладки:
  ```text
  Layer Cycle Manager
  ```
- или команда:
  ```text
  LCM
  ```

---

### 3.5. Обновление CUIX

1. Выполнить:
   ```text
   _MENUUNLOAD
   ```
2. Выполнить:
   ```text
   _MENULOAD
   ```
   и снова выбрать `lcm.cuix`.

---

### 3.6. Полное удаление программы

1. Выгрузить CUIX:
   ```text
   _MENUUNLOAD
   ```
   выбрать `LCM` и нажать «Выгрузить / Unload».
2. В:
   ```text
   OPTIONS → Files
   ```
   удалить папку проекта из:
   - Support File Search Path;
   - Trusted Locations.
3. Удалить переменные окружения в командной строке:
   ```lisp
   (setenv "LCM_PATH" nil)
   (setenv "LCM_CUIX_LOADED" nil)
   ```
4. Переместить или удалить папку проекта.
5. Перезапустить AutoCAD.

## 6. Описание файлов проекта

---

### 6.4. `lcm_main.lsp`

Главный файл программы.

Отвечает за:

- инициализацию Visual LISP COM;
- загрузку модулей:
  - `lcm_config.lsp`;
  - `lcm_data.lsp`;
  - `lcm_core.lsp`;
  - `lcm_ui.lsp`;
- флаг загрузки главного модуля `lcm:loaded`;
- команду `LCM` — открытие диалога;
- команду `LCMRELOAD` — перезагрузка модулей при разработке.

---

### 6.5. `lcm_data.lsp`

Модуль работы с данными чертежа:

- получение списка слоёв;
- поиск точек `AcDbPoint` на слое;
- поиск текстов `AcDbText` / `AcDbMText` на слое;
- сопоставление каждой точки с ближайшим текстом в радиусе (по умолчанию 50);
- формирование имени `Point_<Handle>`, если текст не найден;
- сортировка имён: числовые — по значению, строковые — лексикографически;
- автоматическое сопоставление точек двух слоёв.

---

### 6.6. `lcm_core.lsp`

Модуль геометрии, отрисовки и удаления стрелок:

- расчёт и построение одной стрелки;
- построение линии, залитого наконечника `AcDbSolid`, текста длины;
- назначение слоя и цвета (ByLayer / ACI);
- пакетная отрисовка с undo-блоком;
- поиск построенных стрелок на слое по тексту длины;
- удаление стрелок (текст + отрезок + наконечник) с undo-блоком;
- тестовые команды `LCMTESTDRAW`, `LCMTESTRUN`.

---

### 6.7. `lcm_config.lsp`

Модуль настроек:

- хранение настроек в памяти (`lcm:settings`);
- чтение и запись файла:
  ```text
  settings/lcm_settings.cfg
  ```
- автоматическое создание папки `settings`;
- заполнение отсутствующих ключей значениями по умолчанию;
- применение сохранённого радиуса поиска текста.

Сохраняемые ключи:

| Ключ | Назначение |
|---|---|
| `LAYER_ZERO` | последний выбранный нулевой слой |
| `LAYER_LAST` | последний выбранный последний слой |
| `BY_LAYER` | галочка «По слою» (0/1) |
| `ACI` | последний использованный индекс ACI |
| `TEXT_HEIGHT` | последняя высота текста |
| `SCALE` | последний масштаб |
| `TEXT_SEARCH_RADIUS` | радиус поиска текста около точки |
| `DEL_LAYER` | последний слой удаления стрелок |

---

### 6.8. `lcm_ui.lsp`

Модуль пользовательского интерфейса:

### 8.2. `lcm_data.lsp`

| Имя | Назначение |
|---|---|
| `lcm:get-layers` | отсортированный список слоёв чертежа |
| `lcm:get-points-with-names` | точки слоя с именами: `{имя: (x y)}` |
| `lcm:get-object-coords` | координаты объекта (Coordinates / InsertionPoint) |
| `lcm:get-object-handle` | handle объекта |
| `lcm:is-numeric` | проверка, является ли строка числом |
| `lcm:name<` | сравнение имён для сортировки |
| `lcm:sort-points` | сортировка списка точек по имени |
| `lcm:add-or-replace-point` | добавление или замена точки в списке |
| `lcm:get-point-names` | только имена точек |
| `lcm:auto-mappings` | авто-сопоставление по одинаковым именам |

Алгоритм `lcm:get-points-with-names`:

1. Сканирует Model Space и отбирает объекты указанного слоя.
2. Собирает точки и тексты.
3. Для каждой точки ищет ближайший текст в радиусе `lcm:text-search-radius`.
4. Если текст найден — имя точки равно тексту; иначе `Point_<Handle>`.
5. Возвращает отсортированный список пар `(имя . (x y))`.

### 8.3. `lcm_core.lsp`

| Имя | Назначение |
|---|---|
| `lcm:deg2rad` | градусы в радианы |
| `lcm:pt3` | 2D-точка в 3D-точку ActiveX |
| `lcm:is-string` | проверка строкового типа |
| `lcm:distance-2d` | расстояние только по X и Y |
| `lcm:ensure-layer` | создание слоя при отсутствии |
| `lcm:set-object-properties` | назначение слоя и цвета (ByLayer / ACI) |
| `lcm:draw-arrow` | отрисовка одной стрелки |
| `lcm:run` | пакетная отрисовка по сопоставлениям |
| `lcm:get-line-point` | координаты вершины отрезка |
| `lcm:get-bbox` | габаритный прямоугольник объекта |
| `lcm:point-in-bbox` | проверка попадания точки в прямоугольник |
| `lcm:find-arrows` | поиск стрелок на слое по тексту длины |
| `lcm:delete-by-handle` | удаление объекта по handle |
| `lcm:delete-arrows` | удаление всех стрелок на слое |

Геометрия стрелки:

- линия рисуется от `start` до:
  ```text
  start + (end - start) * scale
  ```
- длина текста считается по исходным точкам без учёта `scale`;
- длина переводится в миллиметры:
  ```text
  длина в мм = длина в метрах × 1000
  ```
  с математическим округлением;
- наконечник — залитый треугольник `AcDbSolid`;
- угол при вершине — 20° (по 10° от оси);
- длина крыла:
  ```text
  0.2 × длина × scale
  ```
- текст размещается строго в точке острия.

Поиск и удаление стрелок:

1. На выбранном слое собираются тексты, отрезки и Solid.
2. Текст считается «текстом длины», если его точка вставки совпадает с концом отрезка (допуск 0.001).
3. К той же точке подбирается наконечник Solid по габаритному прямоугольнику.
4. Количество таких текстов = количество стрелок.
5. Удаление убирает все три объекта каждой стрелки и откатывается одним `Ctrl + Z`.

## 11. Важные допущения и правила

### 11.1. Единицы чертежа

Предполагается, что чертёж выполнен в метрах.

```text
длина в мм = длина в метрах × 1000
```

Округление — по математическим правилам.

### 11.2. Пространство объектов

Программа сканирует:

```text
ModelSpace
```

Объекты в Layout, блоках и XREF не обрабатываются.

### 11.3. Цвет объектов

- галочка «По слою» включена — цвет `ByLayer`;
- выключена — цвет по индексу ACI (1–255), вручную или через родной диалог выбора цвета AutoCAD.

### 11.4. Масштаб

Масштаб влияет только на визуальное удлинение линии:

```text
конец линии = start + (end - start) * scale
```

Длина текста всегда считается по исходным точкам.

### 11.5. Настройки

- сохраняются только при нажатии «Выполнить»;
- восстанавливаются при следующем открытии диалога;
- список слоёв читается заново при каждом открытии диалога, поэтому отдельная кнопка обновления слоёв не требуется;
- кнопка «В чертёж» временно закрывает диалог с сохранением текущего состояния; возврат — командой `LCM` или кнопкой на ленте.

### 11.6. Сопоставления

- имена точек можно выбирать из списков или вводить с клавиатуры;
- введённое имя проверяется: точка с таким именем должна существовать на соответствующем слое;
- имена сравниваются точно, с учётом регистра и пробелов.

### 11.7. Удаление стрелок

- стрелка определяется по тексту длины, примыкающему к концу отрезка;
- удаляются текст длины, отрезок и наконечник;
- точки и их имена на слое не удаляются;
- удаление откатывается одним `Ctrl + Z`.

## 12. Примечания

### 12.1. Кодировка DCL

Файл:

```text
lcm_ui.dcl
```

содержит русские подписи. Если в AutoCAD они отображаются некорректно, сохраните именно этот файл в кодировке:

```text
Windows 1251
```

через VSCode: правый нижний угол → «Save with Encoding» → «Windows 1251».

### 12.2. Ribbon и иконки

1. Размер кнопки на ленте задаётся стилем кнопки в CUI, а не размером файла иконки.
2. Используется стиль:
   ```text
   Большой с текстом (вертикально)
   ```
3. Физический предел иконки на ленте — слот большой кнопки (32×32 логических пикселя).
4. Исходник иконки 215×215 нужен только для чёткости при масштабировании.
5. Иконка встраивается в `lcm.cuix` и работает на других компьютерах без папки `icons`.

### 12.3. Пульдаун-меню

1. Меню:
   ```text
   Меню → Layer Cycle Manager
   ```
   отображается только в классической строке меню.
2. Строка меню включается командой:
   ```text
   MENUBAR
   ```
   со значением `1`.
3. Если строка включена, но пункта нет, меню нужно добавить в текущее рабочее пространство:
   - `CUI`;
   - выбрать текущее рабочее пространство;
   - «Настройка рабочего пространства»;
   - отметить флажком:
     ```text
     LCM → Меню → Layer Cycle Manager
     ```
   - «Готово»;
   - Применить / OK.
4. Меню должно быть верхнего уровня: находиться прямо под узлом «Меню» файла `lcm.cuix`.
