# 05. Грабли AutoLISP

**Статус:** принято 30.10.2026

**Вопрос:** Какие конструкции AutoLISP ломают код неожиданно и как их обходить.

**Решение:** `T` нельзя использовать как имя переменной; `wcmatch` не работает с кириллицей.

## Детали

- **Грабли AutoLISP:** `T` — константа, использовать её как имя локальной переменной нельзя (`неверный объект для внедрения: T`); `wcmatch` не сопоставляет строки с кириллицей — разбор отчётов на нём не построить.
