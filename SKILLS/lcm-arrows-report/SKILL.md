# LayerCycleManager: стрелки → ведомость → Excel

## Главное правило: Excel — часть результата

Если пользователь просит «отрисуй стрелки», «сделай отрисовку», «полный цикл», «посчитай отклонения» — результат всегда **три части**: стрелки в чертеже, ведомость `LCM_ВЕДОМОСТЬ` в чертеже и новый блок в книге Excel.
Делать все три без напоминаний. Только стрелки — лишь по явной просьбе: «без таблицы», «таблицу не надо», «только стрелки».

## Где что лежит

`$W` — папка проекта LayerCycleManager (полный путь подставить один раз, работать из неё). Все пути в командах ниже — **относительные от `$W`**: проект можно перенести на другой компьютер или в другой каталог, и команды не изменятся.

| Файл | Назначение |
|---|---|
| `tools/lcm_cycle.py` | весь цикл одной командой: `status`, `draw`, `table`, `xlsx`, `all`; настройки читает из временного файла |
| `tools/bridge.py` | запуск моста из песочницы DSH: `py -3 tools\bridge.py <глагол> …` (прокси к `cad_bridge.ps1`) |
| `tools/cad_bridge.ps1` | сам мост к запущенному AutoCAD (`status`, `eval`, `load`, `shot`, `undo`, `report`) |
| `lcm_table.lsp` | ведомость отклонений: `(lcm:dev-table <слой A> <слой B> <радиус>)` |
| `tools/lcm_cells_to_json.py` | ячейки ведомости из `_tmp/tbl_cells.txt` → `reports/_table_cells.json` |
| `tools/lcm_table_to_xlsx.py` | блок ведомости в книгу Excel: новый блок вплотную справа от существующих |
| `..\_tmp\lcm_run.cfg` | **временный файл настроек прогона**: создаётся под задачу, удаляется в шаге 10 |
| `reports/` | рабочая папка: отчёты LCM, резервные копии книг, временные выгрузки |

Временный каталог `_tmp` лежит рядом с проектом (в родительской папке); `lcm_cycle.py` вычисляет его от собственного расположения, поэтому от текущего каталога путь не зависит.

## Как обращаться к AutoCAD

Все команды к AutoCAD — `py -3 tools\bridge.py …` из папки проекта. Прямой вызов `.ps1` из песочницы DSH падает с `AuthorizationManager check failed` (процессы низкой целостности не исполняют сценарии), поэтому мост запускается обёрткой — подробности в `docs/research/04-cad-bridge.md`.

- Вызовы к живому AutoCAD требуют полного доступа к системе: режим сессии с полным доступом / «Auto review» либо разовое расширение (`sandbox_permissions: danger-full-access`) с пояснением.
- Команды без AutoCAD (`report`) работают и без расширения.
- **Длинные LISP-выражения** пишутся файлом в `_tmp\` и передаются как `eval "@..\_tmp\имя.lsp"`: кавычки внутри не экранируются, командная строка их не рвёт.

## Быстрый режим (по умолчанию): настройки в файле, цикл одной командой

Агент делает два действия: пишет временный файл настроек и запускает скрипт без аргументов.

**1. Файл `_tmp\lcm_run.cfg`** (в родительской папке проекта; создаётся на каждый прогон):

```ini
# параметры берутся из запроса пользователя
layer_a=<слой нулевого цикла>
layer_b=<слой последнего цикла>
radius=5
scale=<масштаб стрелок>
text_height=<высота текста>
color=by_layer        ; 1..255 — номер цвета ACI, by_layer — цвет по слою
force=1
excel=<книга.xlsx>
cycle=<номер цикла для шапки>
```

**2. Запуск:**

```powershell
py -3 tools\lcm_cycle.py all
py -3 tools\lcm_cycle.py all --show-config     # что прочитано, без AutoCAD
py -3 tools\lcm_cycle.py all --dry-run         # только отчёт, без отрисовки
```

| Ключ файла | Смысл | По умолчанию |
|---|---|---|
| `layer_a`, `layer_b` | слои нулевого и последнего цикла — ровно как в чертеже | обязательны |
| `radius` | радиус сопоставления пар | 5 |
| `scale` | масштаб стрелок | значение LCM |
| `text_height` | высота текста | значение LCM |
| `color` | номер ACI (`10` — красный) или `by_layer` | `by_layer` |
| `force` | перерисовывать, если слой B занят (`1`/`0`) | `0` |
| `excel` | книга для блока ведомости | **обязательна** |
| `cycle` | номер цикла в шапке нового блока Excel | следующий за последним блоком |

Правила:

1. Аргументы командной строки **важнее** файла (`--scale 400` перебьёт `scale=400` из файла) — удобно для разовых проб.
2. Файл создаётся под задачу и **обязательно удаляется** в шаге 10. Если его нет — скрипт работает только от аргументов.
3. Временный файл — не настройки LCM: диалог `LCM` он не меняет, значения `SCALE`/`TEXT_HEIGHT`/`BY_LAYER`/`ACI` подменяются только в памяти и восстанавливаются.

| Фаза | Что делает |
|---|---|
| `status` | AutoCAD запущен, открыт ли чертёж, загружен ли LCM |
| `draw` | сопоставить и нарисовать; `--dry-run` — только отчёт, `--force` — перерисовать |
| `table` | удалить старую и построить новую ведомость `LCMDEV` |
| `xlsx` | ячейки таблицы → блок в книге Excel (`excel` или `--excel путь`) |
| `all` | `draw` → `table` → `xlsx`; при сбое шага следующие не выполняются |

Внутри: проверка слоёв, отказ при занятом слое B (без `--force`), `undo mark`/`undo back` при расхождении числа стрелок, восстановление `SCALE`/`TEXT_HEIGHT`/`BY_LAYER`/`ACI`, сверка `LINE`/`TEXT`/`SOLID` с числом пар, резервная копия книги Excel и проверка блоков после записи.

## Шаг 1. Параметры (если быстрый режим не подходит)

Спросить у пользователя, если не названы; записать в `_tmp\lcm_run.cfg` — это входные данные прогона.
Слои брать из чертежа как есть: `py -3 tools\bridge.py layers`. Имена сравниваются точно — лишняя точка, пробел или регистр дают «слой не найден».

| Параметр | Откуда умолчание | Ключ настройки LCM |
|---|---|---|
| Слои A и B | `LAYER_ZERO`, `LAYER_LAST` из настроек LCM | `LAYER_ZERO`, `LAYER_LAST` |
| Режим | по координатам, радиус 5 | аргумент `r-max` |
| Масштаб стрелок | `SCALE` | `SCALE` |
| Высота текста | `TEXT_HEIGHT` | `TEXT_HEIGHT` |
| Цвет | `BY_LAYER` = 1 (по слою) | `BY_LAYER`, `ACI` |
| Книга Excel | та, что уже используют для этого объекта | — |

## Шаг 2. Проверить обстановку

```powershell
py -3 tools\bridge.py status
```

Ожидается: AutoCAD запущен, открыт нужный DWG, `LCMVersion` не пустой. Если LCM не загружен:

```powershell
py -3 tools\bridge.py load lcm_main.lsp
```

## Шаг 3. Маркер отката (только при ручных шагах)

```powershell
py -3 tools\bridge.py undo mark
```

## Шаг 4. Отрисовка стрелок вручную

Нужно, только если быстрый режим недоступен. `_tmp\draw.lsp` (имена слоёв — из запроса):

```lisp
(progn (setq lcm:old-scale (lcm:config-get "SCALE") lcm:old-th (lcm:config-get "TEXT_HEIGHT") lcm:old-bl (lcm:config-get "BY_LAYER") lcm:old-aci (lcm:config-get "ACI")) (lcm:config-set "SCALE" <масштаб>) (lcm:config-set "TEXT_HEIGHT" <высота>) (lcm:config-set "BY_LAYER" 1) (lcm:geo-run "<слой A>" "<слой B>" <радиус> T))
```

`_tmp\restore.lsp`:

```lisp
(progn (lcm:config-set "SCALE" lcm:old-scale) (lcm:config-set "TEXT_HEIGHT" lcm:old-th) (lcm:config-set "BY_LAYER" lcm:old-bl) (lcm:config-set "ACI" lcm:old-aci) "restored")
```

```powershell
py -3 tools\bridge.py eval "@..\_tmp\draw.lsp"
py -3 tools\bridge.py eval "@..\_tmp\restore.lsp"
```

Первый элемент ответа — число нарисованных пар. При цвете по номеру вместо `BY_LAYER 1` ставить `(lcm:config-set "BY_LAYER" 0)` и `(lcm:config-set "ACI" <номер>)`.

**Если на слое B уже есть стрелки** (`LINE`/`TEXT`/`SOLID` > 0), сначала уточнить у пользователя, перерисовывать ли. При «да» — удалить старые стрелки (только `LINE`, `TEXT`, `SOLID` этого слоя, `POINT` не трогать) либо откатиться на маркер `undo` прошлой отрисовки.

## Шаг 5. Проверить, что стрелки нарисованы

`_tmp\counts.lsp`:

```lisp
(progn (setq r nil) (foreach L (list "<слой A>" "<слой B>") (setq r (cons (cons L (mapcar (function (lambda (ty) (if (setq s (ssget "_X" (list (cons 0 ty) (cons 8 L)))) (sslength s) 0))) (list "POINT" "LINE" "TEXT" "SOLID"))) r))) r)
```

```powershell
py -3 tools\bridge.py eval "@..\_tmp\counts.lsp"
```

`TEXT`, `LINE`, `SOLID` слоя B должны совпадать по количеству и быть равны числу пар. Слой A содержит `TEXT` — это подписи точек, они там были до отрисовки.

## Шаг 6. Ведомость отклонений

Старую таблицу удалить, новую построить — `_tmp\table.lsp`:

```lisp
(progn (setq n 0) (if (setq s (ssget "_X" (list (cons 0 "ACAD_TABLE")))) (progn (setq i 0) (while (< i (sslength s)) (entdel (ssname s i)) (setq i (1+ i) n (1+ n))))) (lcm:dev-table "<слой A>" "<слой B>" <радиус>))
```

```powershell
py -3 tools\bridge.py eval "@..\_tmp\table.lsp"
```

Возврат `(число марок с отклонениями, всего марок, точка вставки)`.

## Шаг 7. Выгрузить ячейки таблицы

`_tmp\export.lsp` — пишет ячейки в `_tmp\tbl_cells.txt` (строка `r;c;текст`):

```lisp
(progn (setq e (ssname (ssget "_X" (list (cons 0 "ACAD_TABLE"))) 0) o (vlax-ename->vla-object e) f (open "<абсолютный/путь/_tmp/tbl_cells.txt>" "w") r 0) (repeat (vla-get-Rows o) (setq c 0) (repeat 4 (write-line (strcat (itoa r) ";" (itoa c) ";" (vla-GetText o r c)) f) (setq c (1+ c))) (setq r (1+ r))) (close f) (list r "ok"))
```

```powershell
py -3 tools\bridge.py eval "@..\_tmp\export.lsp"
py -3 tools\lcm_cells_to_json.py "..\_tmp\tbl_cells.txt" "reports\_table_cells.json"
```

В `open` внутри LISP нужен **абсолютный ASCII-путь** с прямыми слэшами: кириллица и пробелы в пути ломают выражение. В быстром режиме этот шаг делает `lcm_cycle.py`.

## Шаг 8. Заполнить книгу Excel

В быстром режиме этот шаг делает `lcm_cycle.py xlsx` (он сам находит Python с `openpyxl`). Вручную:

```powershell
Copy-Item "<книга.xlsx>" "reports\_backup_<книга>.xlsx" -Force
py -3 tools\lcm_table_to_xlsx.py "<книга.xlsx>" "reports\_table_cells.json" --cycle <номер>
```

Скрипт **дописывает новый блок вплотную справа** от существующих (`A:D` → `E:H` → `I:L` → …), прежние блоки не трогает. В шапке — номер цикла (`--cycle`) и сегодняшняя дата, отклонения подставляет по маркам из таблицы AutoCAD, где данных нет — прочерк, `D` — формула по столбцам своего блока.

## Шаг 9. Проверить результат

Скрипт печатает итог сам: `Excel: {"dimensions": …, "blocks": [["E", 11], …]}` — число в паре с буквой должно совпадать с числом стрелок.

Ожидается: у каждого блока объединения вида `<X>1:<X>3`, `<X+1>1:<X+3>1`, `<X+1>2:<X+3>2`; марок с числами в новом блоке столько же, сколько стрелок.

## Шаг 10. Завершение

- **Чертёж не сохранять** — это делает пользователь сам.
- Сообщить: сколько стрелок нарисовано, сколько марок заполнено, в каком блоке, какой цикл и дата в книге.
- Откат отрисовки — `py -3 tools\bridge.py undo back`.
- Визуальная проверка — `py -3 tools\bridge.py shot -Out "reports\_tmp_arrows.png"`.

## Шаг 11. Убрать за собой (обязательно)

`reports/` — рабочая свалка агента: скриншоты, временный JSON, резервные копии книг. После задачи её нужно чистить, иначе папка за несколько прогонов вырастает в мегабайты. Временный файл настроек `_tmp\lcm_run.cfg` удаляется здесь же.

```powershell
# 1. временные файлы агента — удалить все (включая _tmp проекта)
Remove-Item "..\_tmp\*" -Force -ErrorAction SilentlyContinue
Remove-Item "reports\*.png" -Force -ErrorAction SilentlyContinue
Remove-Item "reports\_table_cells.json" -Force -ErrorAction SilentlyContinue
Remove-Item "reports\*.tmp" -Force -ErrorAction SilentlyContinue
Remove-Item "reports\_write_test.txt" -Force -ErrorAction SilentlyContinue
Remove-Item "reports\agent_dump*.csv" -Force -ErrorAction SilentlyContinue

# 2. резервные копии книг Excel — по одной самой свежей на каждую книгу
Get-ChildItem "reports\_backup_*.xlsx" -ErrorAction SilentlyContinue |
  Group-Object { ($_.Name -replace '_\d{8}_\d{6}\.xlsx$','') } | ForEach-Object {
    $_.Group | Sort-Object LastWriteTime -Descending | Select-Object -Skip 1
  } | Remove-Item -Force

# 3. отчёты LCM — оставить по одному самому свежему на каждую пару слоёв и тип
$csv = Get-ChildItem "reports\*.csv"
$csv | Group-Object { ($_.BaseName -replace '_\d{8,14}$','') } | ForEach-Object {
  $_.Group | Sort-Object LastWriteTime -Descending | Select-Object -Skip 1
} | Remove-Item -Force
```

Правила уборки (пользователь подтвердил 05.11.2026 — **все временные файлы и отчёты удаляются при завершении работы**):

1. **Удалять без вопросов:** `..\_tmp\*` (включая `lcm_run.cfg`), `reports/*.png`, `reports/_table_cells.json`, `reports/*.tmp`, `reports/_write_test.txt`, `reports/agent_dump*.csv` — это артефакты агента, восстанавливать нечего.
2. **Резервные копии книг:** оставлять **одну** самую свежую на каждую книгу, предыдущие удалять.
3. **Отчёты LCM** (`lcm_geo_*`, `lcm_chain_*`, `lcm_check_*`, `lcm_points_*`, `lcm_pair_*`) — временные: в конце работы оставить **по одному самому свежему на каждую пару слоёв и каждый тип**, дубли удалить.
4. Отчёты за текущую задачу, если пользователь их ещё не просмотрел, удалять не раньше, чем закончится задача.
5. В отчёте о работе указывать, сколько файлов удалено и сколько осталось — это подтверждает, что уборка прошла.
6. Если в сессии включена проверка авторизации, уборку надёжнее подтвердить формулировкой в самом запросе: «… и убери за собой» — иначе проверяющий спросит про удаление отдельно.

Целевое состояние папки после уборки: **~15–20 файлов, < 50 КБ** (свежие отчёты по парам + по одной резервной копии книги).

## Правила и грабли (проверено)

1. **Excel строить всегда**, если пользователь явно не сказал «без таблицы»: стрелки без ведомости и блока в Excel — незаконченная задача.
2. **Длинные LISP-выражения.** Мост передаёт выражение временным файлом и грузит через `(load "…")`, поэтому длина не ограничена. Вручную через `SendCommand` по-прежнему держать короче ~500 символов: обрывок длинного текста AutoCAD выполняет как отдельные команды — 11.11.2026 так открылся диалог `LCM`, после чего COM отвечал `RPC_E_CALL_REJECTED`, а шаг Excel упал на «файл занят».
3. **`T` нельзя использовать как имя переменной** в AutoLISP — это константа (ошибка «неверный объект для внедрения: T»).
4. **Кодировки:** `.lsp` — Windows-1251 + CRLF; `.ps1` — UTF-8 с BOM; `.md`, `.py` — UTF-8, переводы строк CRLF.
5. **Не вызывать интерактивные** `LCM`, `LCMCHAIN`, `LCMGEOFILL` — они ждут ввода. Только функции: `lcm:geo-run`, `lcm:chain-run`, `lcm:dev-table`.
6. **Допуск примыкания стрелки к точке — 0.1** (`lcm:dev-tolerance`). При 1.0 соседняя марка забирала чужую стрелку.
7. **Отклонения берутся из нарисованных стрелок**, а не из памяти LCM: сканируется слой последнего цикла, `LINE`, чьё начало совпадает с точкой слоя A; `D` — из подписи у острия.
8. **Ведомость строит строки по всем маркам слоя A**, у марок без стрелки — прочерк.
9. **Excel**: блоки идут вплотную справа (`A:D`, `E:H`, `I:L`, …), старые не перезаписываются, `D` — формула `=(F*F+G*G)^0.5` по своим столбцам, включён `fullCalcOnLoad`; резервная копия книги кладётся в `reports/`.
10. **Перед правкой модулей** — `py -3 tools/lisp_check.py lcm_*.lsp` и `py -3 tools/ref_check.py`; перед коммитом — `py -3 tools/check_all.py` (в русской Windows `python` в PATH часто заглушка Microsoft Store — `py -3` работает всегда).
11. **COM работает только с уже запущенным AutoCAD**: мост не запускает новый экземпляр (иначе появляется пустое «Чертеж1.dwg» и все вызовы уходят в него).
12. **`bridge.py` берёт корень проекта из своего расположения**: `$PSScriptRoot` внутри scriptblock пуст, обёртка подставляет путь сама. Переносить `cad_bridge.ps1` и `bridge.py` нужно вместе.
13. **Слои ищутся по точному имени**: сравнивать с тем, что печатает `py -3 tools\bridge.py layers`; пробел, точка или регистр важны.
14. **`unwind-protect` в AutoLISP 2018 отсутствует** («no function definition»). Возврат настроек делать так: `(setq r (vl-catch-all-apply 'lcm:geo-run ...))`, сразу после — восстановить настройки, затем проверить `vl-catch-all-error-p`.
15. **Мост: файл результата может быть ещё открыт AutoCAD** — быстрые последовательные `eval` падали с «file is being used by another process». Исправлено в `cad_bridge.ps1`: чтение с повтором до 5 с.
16. **Радиус влияет на пары**: слишком большой подтягивает соседние точки (появляются отклонения в метрах). Если отклонение выбивается на порядок — уменьшить `radius` и перерисовать.
17. **LISP-выражение с кавычками — только файлом.** Если передать его строкой в командной строке инструмента (`eval "(progn … \"слой\" …)"`), оболочка рвёт его по пробелам: «A positional parameter cannot be found that accepts argument». Любое выражение со строковыми литералами — файлом в `_tmp\` и `eval "@..\_tmp\имя.lsp"`.
18. **`RPC_E_CALL_REJECTED` («Call was rejected by callee»)** — AutoCAD занят: в командной строке активна команда или запрос (иногда после автоматизации), реже — модальный диалог. Диагностика: `[Runtime.InteropServices.Marshal]::GetActiveObject('AutoCAD.Application').GetAcadState().IsQuiescent` — `False` значит занят, `True` — свободен (проверено 11.11.2026). Лечение: активировать окно AutoCAD и послать `{ESC}` дважды (`SetForegroundWindow` + `SendKeys`), либо попросить пользователя нажать Esc; после этого мост снова работает. Признак диалога — видимое окно класса `#32770` в перечислении окон процесса. Не повторять вызов вслепую: сначала снять занятость.
19. **LCM после перезапуска AutoCAD не загружен** — первый вызов падает с `no function definition: LCM:CONFIG-GET`. Лечится `py -3 tools\bridge.py load lcm_main.lsp`, после чего повторить прогон.

## Если параметры не названы

Брать слои A/B из настроек LCM (`LAYER_ZERO`, `LAYER_LAST`), радиус 5, масштаб и высоту — из настроек LCM, цвет по слою, книгу — ту, что уже используют для этого объекта (спросить, если непонятно). Дальше быстрый режим и уборка — без дополнительных вопросов.
