====================================================
Layer Cycle Manager (LCM) - установка
====================================================

Требования:
- AutoCAD 2018 и новее (полная версия, не LT).

Установка (один раз на компьютере):
1. Скопируйте папку LayerCycleManager в удобное место
2. Откройте AutoCAD.
3. Выполните команду APPLOAD.
4. В окне загрузки найдите и загрузите файл:
   LayerCycleManager\loader\lcm_loader.lsp
5. Выполните команду:
   LCMINSTALL
6. В появившемся окне выбора файла выберите:
   LayerCycleManager\lcm_main.lsp
7. Готово. В ленте Ribbon появится вкладка
   "Layer Cycle Manager" с кнопкой запуска.

Запуск:
- кнопка на вкладке Layer Cycle Manager;
- или команда LCM в командной строке.

Если вкладка не появилась:
- выполните команду _MENULOAD и вручную загрузите файл:
  LayerCycleManager\lcm.cuix

Перенос папки программы:
- если папка программы перенесена в другое место,
  снова выполните LCMINSTALL и укажите новый путь.

Удаление:
- выполните CUIUNLOAD и выгрузите lcm.cuix;
- удалите папку программы из
  OPTIONS -> Files -> Support File Search Path
  и OPTIONS -> Files -> Trusted Locations.
