====================================================
Layer Cycle Manager (LCM) - установка
====================================================

Требования:
- AutoCAD 2018 и новее (полная версия, не LT).

----------------------------------------------------
0. Скачивание программы с GitHub одной командой
----------------------------------------------------

Архив скачивается в ту папку, в которой открыт
cmd или PowerShell (текущая рабочая папка).

CMD:

curl -L -o LayerCycleManager.zip https://github.com/mrpatrickstar26/LayerCycleManager/releases/latest/download/LayerCycleManager.zip

Распаковка в CMD (Windows 10+):

tar -xf LayerCycleManager.zip

PowerShell (скачивание и распаковка одной строкой):

iwr "https://github.com/mrpatrickstar26/LayerCycleManager/releases/latest/download/LayerCycleManager.zip" -OutFile "lcm.zip"; Expand-Archive "lcm.zip" -DestinationPath "." -Force

После распаковки в текущей папке появится:

LayerCycleManager/

Дальше выполни установку по разделу 1 или 2.

----------------------------------------------------
1. Установка способом 1 - установщик (рекомендуется)
----------------------------------------------------

1. Откройте AutoCAD.
2. Выполните команду APPLOAD.
3. В окне загрузки найдите и загрузите файл:
   LayerCycleManager\loader\lcm_loader.lsp
4. Выполните команду:
   LCMINSTALL
5. В появившемся окне выбора файла выберите:
   LayerCycleManager\lcm_main.lsp
6. Готово. В ленте Ribbon появится вкладка
   "Layer Cycle Manager" с кнопкой запуска.

----------------------------------------------------
2. Установка способом 2 - вручную через _MENULOAD
----------------------------------------------------

1. Откройте параметры AutoCAD: OPTIONS.
2. На вкладке Files добавьте папку программы в:
   - Support File Search Path;
   - Trusted Locations.
3. Выполните команду:
   _MENULOAD
4. Выберите файл:
   LayerCycleManager\lcm.cuix
   и нажмите Load.
5. В Ribbon появится вкладка "Layer Cycle Manager".

----------------------------------------------------
3. Запуск
----------------------------------------------------

- кнопка на панели "Стрелки" вкладки
  "Layer Cycle Manager";
- или команда LCM в командной строке.

----------------------------------------------------
4. Перенос папки программы
----------------------------------------------------

Если папка программы перенесена в другое место,
снова выполните LCMINSTALL и укажите новый путь.

----------------------------------------------------
5. Удаление
----------------------------------------------------

1. Выполните CUIUNLOAD неверно - используйте:
   _MENUUNLOAD
   и выгрузите lcm.cuix.
2. Удалите папку программы из
   OPTIONS -> Files -> Support File Search Path
   и OPTIONS -> Files -> Trusted Locations.
3. Удалите переменные в командной строке:
   (setenv "LCM_PATH" nil)
   (setenv "LCM_CUIX_LOADED" nil)
4. Перезапустите AutoCAD.
